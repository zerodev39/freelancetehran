# 🚀 Freelance Tehran


  **A Persian Freelance Marketplace**



  Connecting talented freelancers with clients in Tehran and across Iran.


---

## 📌 About

**Freelance Tehran** is a Persian freelance marketplace designed to connect clients with skilled freelancers.

The platform provides a simple environment where clients can publish projects, freelancers can submit proposals, and both sides can communicate and collaborate.

The project is built with Python and focuses on simplicity, lightweight architecture, and minimal dependencies.

## ✨ Features

- 👤 User registration and authentication
- 💼 Freelancer and client profiles
- 📢 Project publishing and management
- 🔎 Project search and filtering
- 🗂️ Project categories
- 🤝 Proposal submission and management
- 💬 Messaging between clients and freelancers
- ⭐ User ratings and reviews
- 📊 Project status tracking
- 📱 Persian RTL interface

## 🚀 Getting Started

### Prerequisites

- Python 3.8 or higher
- Git

### Installation

Clone the repository:

```bash
git clone https://github.com/zerodev39/freelancetehran.git
```

Navigate to the project directory:

```bash
cd freelancetehran
```

### Run the Application

```bash
python site.py
```

Open your browser and visit:

```text
http://127.0.0.1:8000
```
